条件与循环

条件分支

除了if/elif/else之外，python 3.10+还有一个match/case结构化模式匹配。它的厉害之处在于：匹配结构。

# case _相当于else
# 匹配数据的「形状」并把变量解包出来
point = [10, 20]

match point:
    case [0, 0]:
        print('原点')
    case [x, 0]:
        print(f'在 x 轴上，x = {x}')
    case [0, y]:
        print(f'在 y 轴上，y = {y}')
    case [x, y]:
        print(f'普通点，x = {x}，y = {y}')
    case _:
        print('不是二维坐标')

# 匹配 dict
response = {'status': 'ok', 'data': [1, 2, 3]}

match response:
    case {'status': 'ok', 'data': data}:
        print(f'成功，拿到数据 {data}')
    case {'status': 'error', 'message': msg}:
        print(f'失败：{msg}')
    case _:
        print('未知响应')

函数

函数返回值

return语句用于退出函数，并向调用方返回一个值。

不带值的return等同于返回None。

函数也可以返回多个值：

def division(num1, num2):
    """求商与余数"""
    a = num1 % num2
    b = (num1 - a) / num2
    return b, a

quotient, remainder = division(9, 4)
print(quotient, remainder) # 输出2.0 1

t = division(9, 4)
print(t) # 输出(2.0, 1)，也就是说函数实际返回了一个元组(b, a)

函数的参数

常用的三种参数：默认参数，关键字参数和不定长参数。

  1. 默认参数

    调用时可以不传，用默认值

    def greet(name, greeting='你好'):
    print(f'{greeting}, {name}!')

greet('Alice')              # 用默认值
greet('Alice', '早上好')    # 覆盖默认值

    默认值必须时不可变对象（数字/字符串/元组/None）。不要用list或者dict做默认值，会引发bug。

  2. 关键字参数

    调用时按参数名=值来传，顺序就不重要了。

  3. 不定长参数

    如果调用方传的参数个数不确定，用 *args（接收成 tuple）或 **kwargs（接收成 dict）。

    def sum_all(*nums):
    total = 0
    for n in nums:
        total = total + n
    return total

print(sum_all(1, 2, 3))
print(sum_all(1, 2, 3, 4, 5, 6))

*nums 把所有传入的参数收成一个 tuple，函数里就能用 for 遍历。

**kwargs 类似但收成 dict（少用，先跳过，后面真用到再深入）。

匿名函数

用lambda创建匿名函数。

lambda 最常见的用法是当作参数传给别的函数，比如 sorted 的 key：

users = [
    {'name': 'Alice', 'age': 30},
    {'name': 'Bob', 'age': 25},
    {'name': 'Carol', 'age': 28},
]

# 按年龄排序——临时写个 lambda 当 key
sorted_users = sorted(users, key=lambda u: u['age'])

for u in sorted_users:
    print(u['name'], u['age'])

迭代

在Python中，给定一个 list 或 tuple，我们可以通过 for 循环来遍历它，这种遍历就叫迭代（iteration）。

迭代器

  1. 迭代器是一个可以记住遍历位置的对象。
  2. 迭代器有两个特点：

  • 只能往前，不能后退

  • 用 iter() 把可迭代对象变成迭代器；用 next() 取下一个元素。

字符串、列表、元组都可以用来创建迭代器。迭代器对象既可以用 for 语句遍历，也可以用 next() 函数遍历。

  1. 关键点

    • iter(对象)：把可迭代对象变成 迭代器。

    • next(迭代器)：从迭代器里取出 下一个元素。

    • 当迭代器没有元素可取了，再调用 next() 会抛 StopIteration 异常 —— 所以 while True + try/except StopIteration 是手动遍历迭代器的标准写法。

    • 其实 for 循环本质上就在帮你做上面这些事，只是它把 StopIteration 给你「悄悄」处理掉了。

# next() 函数遍历迭代器
while True:
    try:
        print(next(iter3))
    except StopIteration:
        break

nums = [10, 20, 30]
it = iter(nums)
print(next(it)) # 10
print(next(it)) # 20
print(next(it)) # 30

列表生成式

语法

[expr for iter_var in iterable]
[expr for iter_var in iterable if cond_expr]

  • 第一种：迭代 iterable 里所有内容，把每次的元素放到 iter_var 中，再用前面的 expr 计算出新值，组成新列表。

  • 第二种：在第一种基础上加了 if 判断，只有满足条件的元素才会被处理。

list1 = [x * x for x in range(1, 11)]
print(list1) # [1, 4, 9, 16, 25, 36, 49, 64, 81, 100]

list2 = [x * x for x in range(1, 11) if x % 2 == 0]
print(list2) # [4, 16, 36, 64, 100]

生成器

在python中，这种一边循环一边计算的机制，称为生成器（generator）。使用了yield的函数被称为生成器。

跟普通函数不同的是，生成器是一个返回迭代器的函数，只能用于迭代操作，更简单点理解：生成器就是一种迭代器。

在调用生成器运行的过程中，每次遇到 yield 时函数会 暂停并保存当前所有的运行信息，返回 yield 后面的值；下一次执行 next() 方法时，从当前位置 继续运行。

  1. 创建方式：函数+yield
def my_func():
    for i in range(1, 11):
        yield i

print(myfunc()) # <generator object my_func at 0x...>输出的不是1-10，而是生成器对象
# j = my_func()
# print(next(j)) # 输出1
# print(next(j)) # 输出2

for j in my_func(): # 用for循环遍历出所有值
    print(j)
  1. 执行方式：暂停+继续
def odd():
    print('step 1')
    yield 1
    print('step 2')
    yield 3
    print('step 3')
    yield 5

o = odd()
print(next(o)) # 输出step 1 1
print(next(o)) # 输出step 2 3
print(next(o)) # 输出step 3 5

可以看到，odd 不是普通函数而是 generator，在执行过程中遇到 yield 就中断，下次又继续执行。三次 yield 后已经没有 yield 可执行了，如果再 next(o)，就会抛 StopIteration 异常。

同时迭代多个序列：zip()

zip()函数可以同时迭代多个序列，每次分别从一个序列中取一个元素：

name = ['Alice', 'Bob', 'Jack']
age = [18, 25, 20]
for i, j in zip(name, age):
    print(i, j)

枚举（enumerate）

写 for 的时候，如果你 既要值又要下标，可以用 enumerate()：

fruits = ['苹果', '香蕉', '橘子']
for i, fruit in enumerate(fruits):
    print(i, fruit)

  • 对象

三大特性

  • 封装

  • 继承

    继承就是子类自动获得父类的所有属性和方法——可以再加自己的，也可以「重写」父类的。

    • 直接继承

      class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        print(f'我叫 {self.name}，今年 {self.age} 岁')

class Student(Person):
    pass   # 啥都不加，但已经继承了 __init__ 和 greet

s = Student('小明', 16)
s.greet()

    • 子类添加自己的属性和方法

      class Student(Person):
    def __init__(self, name, age, school):
        super().__init__(name, age)   # 调父类的 __init__
        self.school = school

    def study(self):
        print(f'{self.name} 正在 {self.school} 学习')

s = Student('小明', 16, '希望小学')
s.greet()
s.study()

  • 多态

多态：对不同类型的对象做相同的操作，会根据类型的不同表现出不同的行为。

简单说就是「重写父类的方法」——子类的同名方法盖掉父类的。

class Animal:
    def sound(self):
        print('一些声音')

class Dog(Animal):
    def sound(self):
        print('汪汪')

class Cat(Animal):
    def sound(self):
        print('喵喵')

# 注意：调用方都是 .sound()，但是行为完全不同
animals = [Dog(), Cat(), Animal()]
for a in animals:
    a.sound()

模块

在 Python 中，一个 .py 文件就是一个模块（Module）。

模块的使用

  1. import
  2. from … import
  3. from … import *（不推荐）
  4. 起别名(as)

主模块和非主模块

  • 主模块：被直接运行的那个.py文件

  • 非主模块：import进来的那个模块

__name__属性：

Python 给每个模块都设置了一个特殊变量 __name__：

  • 模块被 直接运行 时，__name__ 的值就是字符串 '__main__'

  • 模块被 import 时，__name__ 的值就是模块名本身

所以经典写法是：

# mymod.py

def main():
    print('正在运行 main 逻辑')

if __name__ == '__main__':
    main()

效果：

  • 直接 python mymod.py → 打印 正在运行 main 逻辑

  • 别的文件 import mymod → 不会自动跑 main()，函数依然可以被调用
